# 油画切片开场（视频同款四拍）

`scripts/oil_opening.py` 一条命令把静态封面改成"短视频开头"那种质感：照片卡扇形炸开 → 圆环拼贴旋进 → 整屏油画切成竖切片向两侧铺满 → 毛玻璃面板从左边擦入 → 原有文字层接着进场。全程是原生 DrawingML 动画，WPS / PowerPoint 里真播，文件仍是可编辑 .pptx，不生成、不嵌入视频。

## 一、四拍时间轴（默认值，`--text-start` 可整体推后文字）

| 拍 | 时间 | 动作 | 实现 |
|---|---|---|---|
| 1 | 0.09s 起，错峰 34ms | 卡片从画外飞进扇形位，边飞边转（‑52° 起，每张 +15.5°） | `animMotion` + `animRot` |
| 2 | 1.00s 起，错峰 16ms | 卡片再转 +52°，然后整叠位移退回画外 | `animRot` + `animMotion`（反向） |
| 3 | 1.04s / 1.90s | 圆环从画外左侧滑到画面中心，停一拍，再斜着旋出 | 只用 `animMotion` |
| 4 | 1.52s 起，错峰 22ms | 12 条竖切片从画面中心那一点向两侧分开、各自 700ms 撑满 | `animEffect fade 240` + `animMotion` from 偏移 |
| 5 | 2.30s，900ms | 毛玻璃面板从左擦入，盖住左侧 ~65% | `animEffect wipe(left)` |
| 6 | 3.30s 起 | 原有文字/正文/照片接着播（原延迟压缩到 0.55 倍） | 改写原 `stCondLst/cond@delay` |

底图统一在 1.25s 淡入（520ms）、压暗层在 1.95s —— 这样开场前 1 秒是纯黑，圆环那拍画面才亮起来，跟参考视频一致。

## 二、几何（全部相对页宽/页高，换尺寸不用改代码）

| 项 | 比例 | 说明 |
|---|---|---|
| 支点 `pivot` | (0.454, 0.420) | 扇形圆心，也是切片"炸开"的原点 |
| 卡片 | 宽 0.1425 页宽，高宽比 0.71 | 8 张；终点中心 X 从 0.259 起步，间距 0.0465 |
| 圆环 | 宽 0.315 页宽 | 候场位 ‑0.705 页宽（画外左侧） |
| 切片 | 12 条，竖缝 9px / 描边 2px（按 2400px 画布折算） | 偶列下移 14px、奇列上移 12px，制造手裁错位感 |
| 面板 | 0.655 页宽 + 0.030 羽化 | 毛玻璃 = 底图高斯模糊 46px + 压亮 0.62 + 混 16% 深蓝 + 混 10% 冷白 |

## 三、素材怎么来的

不用额外找图：默认把**封面那张满版底图**（面积 ≥ 80% 页面）当油画，`--art` 可换。

- 切片：整幅图按列裁开 → 每列上下错位 → 2px 浅灰描边 → 整图 vignette 0.86。
- 面板：同一幅图取出左 65%，模糊 + 提亮 + 混色，右沿 3% 羽化，做成"毛玻璃"。
- 照片卡：同一幅图随机 10 组 0.48~0.62 的取景，套白边 + 投影，做成"一叠照片"。
- 圆环：沿 12 个扇区各贴一片同一幅图的裁片，中空（内径 300 / 外径 620）。

素材落在 `--work` 目录（默认系统临时目录 `oil_opening/`），按油画哈希命名，同一张图重复跑会复用。

## 四、最需要小心的地方（WPS 实测）

1. **图片会提前显示**：WPS 对"延迟进场"的图片不隐藏。所以卡片、圆环、切片一律**设计位 = 成品位**，动画只做位移（`M 0 0 L dx dy` 或 `M dx dy L 0 0`）。千万别指望入场效果帮你在延迟前藏住它。
2. **`animScale` 用在图片上不可靠**：设 `from=52%` 会停在 52%，永远长不到 100%。要"从一点长大"就改成分条位移展开。
3. **`exit fade` 用在图片上不可靠**：淡出没反应，卡片会一直压在标题上。退场一律用"再位移回画外"。
4. **`animMotion` 的 dy 在图片上偶尔失效**：切片一律 `dy=0`（纯水平展开）最稳；卡片/圆环带 dy 是可以的，但别给切片加。
5. **`animRot` 正常可用**，卡片旋转没问题。
6. **动画 id 必须全页唯一**：本脚本从封面原有 `cTn` 的最大 id 往后编号，跑完可以自查 `cTn id="x"` 有无重复。
7. **层级必须三层**：`par(delay=indefinite) → par(delay=0) → 各效果 withEffect`；`p:timing` 要落在 `cSld / clrMapOvr / transition` 之后。

## 五、z 序（错了会被挡）

切片插在**封面最大底图之后一位**（盖底图、不盖文字），面板接在切片之后，卡片和圆环 `append` 到最上层（要压过面板和文字）。脚本已按这个顺序插入，别手动调。

## 六、常见返工点

- 封面原有的"照片填充大字横穿"和碎三角会跟开场抢镜头 → `--drop "shard0,shard1,bemyself"` 先删掉再跑。
- 文字来得太早/太晚 → `--text-start 3800`（默认 3300）。
- 面板太宽挡住主体 → `--panel 0.55`；切片太密 → `--bars 9`。
- 想要更"碎"：加大 `G["gap_px"]`（默认 9，按 2400px 画布）并同步 `edge_px`。

## 七、验收

跑完必须抓帧确认，别凭"应该能播"交付：

```powershell
& $PY scripts\oil_opening.py --deck 静态.pptx --out 开场版.pptx --dry-run   # 先看方案
& $PY scripts\oil_opening.py --deck 静态.pptx --out 开场版.pptx
& $PY scripts\verify_playback.py --pptx 开场版.pptx --frames 18 --interval 0.12 --out 开场抽帧.jpg
```

拼贴图里应当依次看到：全黑 → 白边卡片扇形 → 圆环 → 竖切片从中间向两侧铺开 → 左半毛玻璃 → 文字。
