# 封面开场：分镜与机制

参考对象是抖音上常见的"深色雪山 + 巨型英文词 + 玻璃面片"PPT 模板（57 秒、1280×720）。看上去像视频，其实是**七层元素在不同时间点各自进场**堆出来的镜头感。这个 skill 就是把那套时序搬进原生动画。

## 12 秒分镜表

| t (ms) | 层 | 动作 | 视觉效果 |
|---|---|---|---|
| 0 | 背景图 | 淡入 900ms，同时 14s 内从 100% 推到 105% | 黑场里雪山慢慢显影，画面持续极缓推近，避免"死图" |
| 120 | 压暗层（满版） | 淡入 600ms | 把底图压到能读字的亮度 |
| 220 | 照片填充大字 | 淡入 700ms | 字先"隐隐出现" |
| 1300 | 同上 | 位移 4200ms，`dx=-2.45` 页宽 | 巨型字从画面右侧横穿到左侧并离场，字里透出山脊（关键镜头） |
| 2600 | 主标题 | 擦写 900ms | 从右往左刷出来（wipe right） |
| 3450 | 副标题 | 擦写 900ms | 与主标题形成"两拍" |
| 3760 | 金色细线 | 擦写 700ms | 把标题与正文分开 |
| 3960 起 | 正文行 | 淡入 + 上浮 18px，错峰 150ms | 一行一行"抬"起来，读起来有节奏 |
| 4000 起 | 玻璃面片 | 淡入 800ms + 旋转 18°/2400ms + 侧移 0.22 页宽 | 半透明三角面片掠过，制造空间纵深 |
| 4520 | 人像 + 白框 | 从画布外滑入（0.55 页宽）+ 淡入 + 96→100 缩放 | 主角登场 |
| 5600 | 尾注 | 淡入 | 落版信息 |

总长约 6.5 秒可播完，讲者开口时画面已稳定；如果要更慢，把 `sweep_dur` / `row_stagger` 调大即可。

## 为什么这几个动作"像视频"

1. **持续推近（慢 zoom）**：静止底图 + 缓慢放大，人眼会读成"镜头在动"。这是最便宜也最有效的一招，内页同样适用（14s 推到 105%）。
2. **照片填充大字**：字不是纯色，而是把雪山图裁进字形里（`background-clip:text`），文字和背景共享同一张图 → 天然的"同一场景"感。
3. **横向穿越 + 离场**：字从画外进来再出画，而不是原地淡入，才有"运镜"；位移距离用页宽倍数（`sweep_dx`），换尺寸不用重算。
4. **擦写而非淡入**：标题擦写的边缘在动，比淡入更像"镜头对焦"；一个 0.9s 的 wipe 比 0.5s 的 fade 更有存在感。
5. **错峰 150ms**：正文行同时淡入会糊成一团，错峰后眼睛能跟着走。
6. **面片旋转**：3D 空间翻飞做不出来（WPS 不支持），2D 三角 + 旋转 + 侧移在观感上接近，且不会崩。

## 参数怎么调

- 想让大字"更狠"：`sweep_dx` 改到 `-3.2`，`sweep_dur` 缩到 3200（更快掠过）。
- 想让开场更慢更庄重：`bg_fade 1200`、`title_delay 3200`、`row_stagger 220`。
- 人像要早出现（怕它太晚）：`photo_delay` 改 1200，同时把 `sweep_delay` 提前到 600。
- 面片太多会乱：`shard_stagger` 改 140，或干脆把 `shard_delay` 设成 999999（等于不出现）。
- 换 16:9 / 4:3：位移全用页宽/页高倍数，不用改数值。

## 失败症状对照

| 看到的现象 | 原因 | 处理 |
|---|---|---|
| 大字不动 | `animMotion` 少了 `origin="layout"` | 用脚本生成，别手改 |
| 字一进画面就停住/位移方向反了 | `path` 的 `L` 后是相对位移，不是绝对坐标 | 负数 = 向左；`sweep_dx` 传负值 |
| 人像一开始就在画面上 | WPS 不隐藏延迟进场的图片 | 靠 `photo_slide_dx` 把它先挪到画布外 |
| 每页开头闪白 | 满版图淡入时露出白底板 | 设 `bg_color`（默认 `06080C`） |
| 动画完全不播 | `timing` 层级不对，或没写 `nodeType="withEffect"` | 见 `wps-timing-xml.md` |
| 播放卡顿 | 单页效果太多（>60 个 par） | 拆层：把同组小元素合成一组 |
