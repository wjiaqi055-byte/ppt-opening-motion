# 深色雪山版式口径（配套封面用）

动效是加在静态版面之上的，版面本身先要"像影像"而不是"像幻灯片"。这套口径来自深色雪山模板，实际做过 24 页答辩 PPT，可复用于汇报、路演、竞赛。

## 色板

| 用途 | 值 |
|---|---|
| 主文字 | `#EDEFF2` |
| 次文字 | `#B6BEC7` |
| 纯白（标题/强调） | `#FFFFFF` |
| 金色（kicker、数字、强调行） | `#D8B778` |
| 冷蓝（次级信息、链接感） | `#9FB4C6` |
| 灰（注释、页码） | `#8C949D` |
| 卡片底 | `#0C1016`（可叠 60~80% 透明） |
| 细线 | `#3A424B` / `#566069` / `#66717B` |
| 页面底色 | `#06080C`（配合 `bg_color` 消除白闪） |

## 字体与字阶（1280×720 画布）

- 标题 44px 白色粗体；次行 20px `#B6BEC7`；正文 17~20px。
- kicker（栏目标签）15px 金色，字距 3，配 96px 短线。
- 中文正文可用 KaiTi 做"引文/署名"的另一种声调；数字与英文用 Times New Roman 拉开层次。
- 一页只允许一个 44px 标题，其余靠字重和颜色分层，不靠加粗堆叠。

## 图片处理

- 满版底图选**有纵深的山脊/星空**，纵向构图优先；上面必须压一层竖向渐变 `#06080C` 从 0.90 → 0.82 → 0.90，否则文字读不动。
- 人像照统一加 2px 白框，与深底形成"贴片"感；配一句小字说明（时间 + 场合）。
- 作品截图用手机竖图直接放，不加手机壳描边——真实感来自未修饰。

## 照片填充大字

- 用 `scripts/make_photo_text.py` 生成：`background-clip:text` + 同一张底图做填充，导出透明 PNG。
- 字号约为画布高度的 35~40%（720 画布 ≈ 240~280px），字距 4~8px。
- 放置时让字的基线略高于画面中线，起始位置在画布右侧外面（`x ≈ 1.01 页宽`），由路径动画带进来。

## 玻璃面片

- 5 块左右的三角/四边形，填充白色 6~10% 透明，描边白色 20~30%。
- 面积都在页面 3~6%，分散在四个象限，避免互相重叠成"一坨"。
- 动效上给 18~22° 旋转 + 0.2 页宽侧移，就足够"空间感"；不要再加 3D 翻转（做不出来）。

## 版式骨架（内容页）

1. 左上 kicker（金色英文栏目 + 中文副标），下面 44px 标题，再下面一行 20px 说明。
2. 主体分 2~3 栏：左栏文字块、右栏图或卡片；栏间留 40~56px 空隙。
3. 页脚：y≈646 一条细线，线左侧写数据来源，右侧写页码 `x / N`。
4. 每页只讲一个判断，结论放标题，不要放在最后一行。
